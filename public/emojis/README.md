# Custom emoji assets

Raster emoji files live here and are served as-is (no resizing / re-encoding),
so copying and downloading always hands over the original pixels.

| File                  | Registered in                 |
| --------------------- | ----------------------------- |
| `crying-laughing.png` | `src/data/assetEmojis.ts`     |

To add a new one:
1. Drop the file in this folder (PNG with transparency recommended).
2. Add an entry to `ASSET_EMOJIS` in `src/data/assetEmojis.ts`.
